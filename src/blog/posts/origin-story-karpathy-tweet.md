# The Origin Story: Karpathy's Tweet That Named a Movement

Every buzzword has a birth certificate. Vibe coding's is a two-paragraph post on X, written on **February 2, 2025**.

## The post

Andrej Karpathy wrote:

> There's a new kind of coding I call "vibe coding", where you fully give in to the vibes, embrace exponentials, and forget that the code even exists. It's possible because the LLMs (e.g. Cursor Composer w Sonnet) are getting too good. Also I just talk to Composer with SuperWhisper so I barely even touch the keyboard.
>
> I ask for the dumbest things like "decrease the padding on the sidebar by half" because I'm too lazy to find it. I "Accept All" always, I don't read the diffs anymore. When I get error messages I just copy paste them in with no comment, usually that fixes it. The code grows beyond my usual comprehension... Sometimes the LLMs can't fix a bug so I just work around it or ask for random changes until it goes away.
>
> It's not too bad for throwaway weekend projects, but still quite amusing. I'm building a project or webapp, but it's not really coding — I just see stuff, say stuff, run stuff, and copy paste stuff, and it mostly works.

## Why it resonated

Three things made the post stick.

**It named a feeling.** Thousands of developers had already drifted into this workflow without a word for it. Karpathy gave them vocabulary.

**It came from authority.** This was not a marketing slogan from a vendor. It was a candid observation from someone who had led AI at Tesla and helped found OpenAI.

**It was honest about the limits.** The phrase *"throwaway weekend projects"* was not an accident. Karpathy drew the boundary himself, long before the critics arrived.

## A history of one idea

Karpathy had been circling this theme for two years. In **January 2023** he declared that "the hottest new programming language is English." Vibe coding was the practical follow-through: if English is the language, then a prompt is the program and the LLM is the compiler.

By **December 2025**, Karpathy reported that roughly 80% of his own code was AI-generated. By **April 2026**, at Sequoia's AI Ascent event, he declared vibe coding passé and proposed a successor term: *agentic engineering*.

## The takeaway

The origin story is worth remembering because it sets the terms of the debate. Vibe coding was never sold as a way to run critical infrastructure. It was described — by its inventor — as a fast, loose, delightful way to make throwaway things.

Almost every controversy since has come from ignoring that framing.
